Como usar isto

1
Arrancar o painel. No terminal: cd jev-trader && pip install -e ".[dev]" && python -m jev_trader.ui.server e abre http://127.0.0.1:8787.
2
Testar a canalização sem rede. No Painel, juiz = Demo, carrega ▶ Iniciar. O Demo inventa veredictos a partir do momentum do próprio tape (sem qualquer skill) só para veres entradas, saídas, escalações e o kill switch a funcionar. O Stub neutro nunca entra.
3
Ligar o Reflex real. Cria uma chave em console.typesafe.ai, export TYPESAFE_API_KEY=... antes de arrancar o servidor, escolhe juiz = Jev. Cada vela faz UMA chamada com os 8 setups em paralelo. Opcional: export ANTHROPIC_API_KEY=... e marca "Escalar para Claude Opus 5.5".
4
Deixar correr em papel. Tudo o que vês aqui é paper trading com um modelo de custos. Nenhuma ordem real pode sair deste repositório: o adaptador live está deliberadamente por implementar (docs/05-ship.md).
5
Alertas de setups. Separador "Alertas": ativa notificações do browser (pede permissão) e som. Para receber no telemóvel, cria um bot no @BotFather, exporta TELEGRAM_BOT_TOKEN e TELEGRAM_CHAT_ID antes de arrancar o servidor; ou JEV_WEBHOOK_URL para Discord/Slack. "Setup LONG/SHORT" dispara quando um símbolo passa todas as portas; "a formar" avisa antes.
6
Revisão noturna. Separador "Revisão noturna" → Correr. Mede Brier/skill/ECE por setup, lista fills e misses e propõe um setups.yaml novo. Só substitui o atual quando carregares "Aprovar".
7
Regra de sobrevivência. Não passes de papel para dinheiro enquanto a revisão não mostrar skill > 0 em pelo menos 2 setups com n ≥ 100. O sistema a não fazer nada é o estado correto até o merecer.

As portas de entrada (qualidade ≥ 2, confiança > 0.80, risco = safe), o quarter-Kelly e todos os limites estão em código (policy.py, risk.py). O Jev só responde a perguntas tipadas; o Brain só pode dizer resume / pause / reduce / flatten.
